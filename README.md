# Admin Notes (Demo)

Malý ukázkový WordPress plugin pro portfolio.

## Co dělá
- Přidá metabox do editoru příspěvků/stránek pro interní poznámku (viditelnou jen v administraci).
- Ukládá data jako post meta.

## Co ukazuje (technicky)
- WordPress hooks
- Metabox UI
- Ukládání post meta
- Nonce + capability checks
- Čistá struktura pluginu (namespacing, třídy)

## Stav
- v0.1.0: scaffold
