# CTA Block (Demo)

Jednoduchý Gutenberg blok pro výzvu k akci (text + tlačítko).
Blok se renderuje na serveru (PHP), editor UI je řešené bez buildu.

## Funkce
- Text + tlačítko (URL)
- Server-side render (save() vrací null)
- Bez build toolingu (žádné npm)

## Instalace
1. Nahraj složku `cta-block` do `wp-content/plugins/` (nebo ji symlinkni)
2. Aktivuj plugin
3. V editoru najdi blok **CTA (Demo)**
